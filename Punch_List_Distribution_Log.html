About this list

This page has no form of its own. It reads wesco_punch_lists_v1 and wesco_recipient_files_v1 — the exact same localStorage keys the Master Punch List page writes to — and shows every item from a job the moment that job is Sent to a recipient. Jobs that are only Saved (never Sent) won't appear here yet.

Checking the Completed box updates the item on the shared punch list record itself, so it stays in sync with the Master Punch List. Since this all lives in browser localStorage, it's local to this device/browser — the notes in the Master Punch List about a shared backend (SharePoint list / Dataverse / Power Automate) apply here too.
