ℹ How this template works right now

This page reads and writes Employee Hardware Log.xlsx directly through the /api/employees and /api/employees/{sheet}/hardware endpoints (Azure Functions calling Microsoft Graph). "Add Employee" copies the TEMPLATE sheet in the real workbook; "Add Hardware Item" appends a row to that employee's table. Whatever you see here is the actual file — and whatever's in the file shows up here on refresh.
