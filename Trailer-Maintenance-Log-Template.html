ℹ How this template works right now

This page reads and writes Trailer Maintenance Log - Copy.xlsx directly through the /api/trailers and /api/trailers/{sheet}/visits endpoints (Azure Functions calling Microsoft Graph). "Add Trailer" copies the Template sheet in the real workbook; "Add Service Visit" appends a row to that trailer's Visits_… table. Whatever you see here is the actual file — and whatever's in the file shows up here on refresh.
