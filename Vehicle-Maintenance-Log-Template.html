ℹ How this template works right now

This page reads and writes Vehicle Maintenance Log - Copy.xlsx directly through the /api/vehicles and /api/vehicles/{sheet}/visits endpoints (Azure Functions calling Microsoft Graph). "Add Vehicle" copies the Template sheet in the real workbook; "Add Service Visit" appends a row to that vehicle's Visits_… table. Whatever you see here is the actual file — and whatever's in the file shows up here on refresh.

This is a separate tool from the older "Vehicle Log" card elsewhere on this hub, which tracks registration/driver assignment rather than service history and cost.
